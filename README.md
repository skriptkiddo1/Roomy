# Roomy

<p align="center"><img src="docs/roomy.gif" width="160" alt="Roomy - робот-микросхема"></p>

<p align="center"><i>«Память не надо чистить. Надо знать, кто её ест».</i> - Roomy, робот-микросхема</p>

**Помощник для слабых компьютеров на Windows.** Показывает, куда уходят память и место на диске, объясняет простыми словами, что за программы работают в фоне, и помогает освободить ресурсы - бережно и только с вашего согласия.

[English](README.en.md)

> ⚠️ **Программа пока без цифровой подписи** (подпись стоит денег, а broski пока копит). Поэтому при первом запуске Windows может показать синее окно SmartScreen - нажмите «Подробнее» → «Выполнить в любом случае». «Интеллектуальное управление приложениями» в Windows 11 может её вообще заблокировать. Исходники открыты - можно проверить, что внутри нет ничего лишнего, или собрать самому.

Говорит по-русски и по-английски: язык берётся из Windows, а сменить его можно вручную - правый клик по значку в трее → «Язык / Language».

## Принципы

- **Ничего не делает молча.** По умолчанию Roomy только показывает, что происходит. Что притормаживать, закрывать или удалять - решаете вы.
- **Объясняет, а не пугает.** Никаких «ваш компьютер в опасности» и «ускорения в 10 раз». Только понятные причины и честные советы.
- **Не «чистит» память.** Принудительная очистка оперативной памяти (как у Mem Reduct) не ускоряет компьютер, а заставляет программы потом подгружать данные с диска. Roomy работает с причинами: какие программы и вкладки держат память.
- **Лёгкий.** Один файл ~300 КБ, без установки. Работает на встроенном в Windows .NET Framework 4.8.
- **Приватный.** Не собирает и не отправляет никаких данных. Подробнее - в [PRIVACY.md](PRIVACY.md).

## Что умеет

**Память**
- В трее живёт робот-микросхема **Roomy** (да, его зовут как программу): спокоен, когда памяти хватает, напрягается, когда её мало, и иногда моргает. Можно переключить на процент занятой памяти (правый клик по значку → «Значок в трее»). Понятный статус: «Всё в порядке», «Памяти впритык», «Памяти мало», «Не хватает памяти».
- Список программ по памяти с объединением процессов (19 процессов браузера - одна строка), рост за 10 минут, график.
- Режимы для каждой программы: **не трогать** / **притормаживать в фоне** (пока вы в ней не работаете, Windows в первую очередь забирает память у неё) / **можно закрывать** (её закрывает «Режим экономии» и потом запускает обратно).
- Уведомление, когда памяти мало, с самыми прожорливыми программами.

**Что это за процесс?**
- Встроенная база ~100 частых процессов Windows, драйверов и программ: что это, можно ли трогать, что будет, если закрыть.
- Факты о файле: путь, издатель, цифровая подпись (включая каталоги Windows).
- Предупреждения о подозрительном: системное имя не из папки Windows, запуск из временной папки, незнакомая неподписанная программа. Кнопка проверки на VirusTotal по отпечатку файла (сам файл никуда не отправляется).

**Место на диске**
- Безопасная очистка по категориям с объяснениями: временные файлы, кэш браузеров и программ, отчёты об ошибках, кэш шейдеров, старые установщики (в корзину), корзина.
- Что занимает больше всего: крупные папки (с точностью до конкретной подпапки), крупные файлы, одинаковые копии ваших файлов.

**Проверка компьютера**
- Память (можно ли добавить планку или она распаяна), тип системного диска (HDD или SSD), свободное место, файл подкачки, сжатие памяти, автозагрузка, режим питания, время без перезагрузки, фоновые «помощники», браузер, изоляция ядра - с объяснением и кнопкой, открывающей нужную настройку Windows.

## Roomy Tabs - расширение для браузера

Усыпляет вкладки, которые вы давно не открывали. Не трогает вкладки со звуком, с набранным текстом, закреплённые и сайты из исключений. В Chrome и Edge учитывает свободную память: когда её мало, вкладки засыпают раньше. Исходники - в папке [`extension/`](extension/).

## Скачать

Готовые файлы - на странице [Releases](../../releases): `Roomy.exe` и архивы расширения. Рядом лежит `SHA256SUMS.txt` для проверки целостности.

Требования: Windows 10 (1903+) или Windows 11, 64-бит.

## Сборка из исходников

Нужен .NET SDK 8 (Windows):

```
dotnet build src/Roomy/Roomy.csproj -c Release -o out
python extension/build.py
```

Каждое изменение в ветке `main` автоматически собирается в GitHub Actions. Когда публикуется релиз, готовые файлы прикладываются к нему сами.

## Вопросы, которые никто не задавал

**Почему робот?** Потому что смотреть на проценты скучно, а на микросхему, которая потеет, когда памяти мало, - нет. Если нужно по-взрослому, правый клик по значку → «Значок в трее» → «Процент памяти».

**Почему он моргает?** Чтобы было видно, что Roomy жив и не завис. Не нравится - там же, «Робот моргает», выключается.

**А если на него нажать в окне программы?** Попробуйте.

**Почему автор - скрипт-кидди?** Каждый с чего-то начинал. Главное, что программа делает только то, что вы разрешили.
