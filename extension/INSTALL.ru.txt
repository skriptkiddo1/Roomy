Roomy Tabs 0.1.0 — как установить и как опубликовать
=====================================================

ЧТО В ПАПКЕ
  chrome\                            — распакованное расширение для Chrome и Edge (для установки у себя)
  roomy-tabs-chrome-0.1.0.zip     — архив для Chrome Web Store и Edge Add-ons
  roomy-tabs-firefox-0.1.0.zip    — архив для Firefox (установка у себя и addons.mozilla.org)
  PRIVACY.md                         — политика конфиденциальности (магазины просят ссылку на неё)
  STORE-LISTING.txt                  — готовые тексты для страницы расширения в магазинах


УСТАНОВИТЬ У СЕБЯ
-----------------
Chrome / Edge (работает сразу и навсегда):
  1. Откройте chrome://extensions  (в Edge — edge://extensions)
  2. Включите «Режим разработчика» (переключатель вверху справа; в Edge — слева внизу)
  3. «Загрузить распакованное расширение» → выберите папку chrome
  4. Закрепите значок расширения на панели (иконка-пазл → булавка)
  Папку chrome после этого не удаляйте и не перемещайте — браузер берёт файлы из неё.

Firefox — нужна версия 140 или новее (Меню → Справка → О Firefox).
  Обычный Firefox устанавливает навсегда только расширения, подписанные Mozilla.
  Вариант А — попробовать прямо сейчас (до перезапуска Firefox):
    1. Откройте about:debugging#/runtime/this-firefox
    2. «Загрузить временное дополнение…» → выберите roomy-tabs-firefox-0.1.0.zip
  Вариант Б — навсегда (подпись Mozilla, бесплатно, обычно несколько минут, без публикации в каталоге):
    1. Войдите на https://addons.mozilla.org/developers/ (аккаунт Mozilla)
    2. «Submit a New Add-on» → «On your own» (распространять самому)
    3. Загрузите roomy-tabs-firefox-0.1.0.zip, дождитесь проверки
    4. Скачайте подписанный .xpi и перетащите его в окно Firefox


ОПУБЛИКОВАТЬ ДЛЯ ВСЕХ
--------------------
Перед публикацией: выложите PRIVACY.md в открытый доступ (например, в репозиторий на GitHub
или на GitHub Pages) — магазины просят ссылку на политику конфиденциальности.
Понадобятся скриншоты 1280×800 и короткое/полное описание — тексты в STORE-LISTING.txt.

Chrome Web Store — разовый взнос $5:
  https://chrome.google.com/webstore/devconsole → регистрация → «Новый элемент» →
  загрузите roomy-tabs-chrome-0.1.0.zip → заполните описание, скриншоты, раздел
  «Конфиденциальность» (обоснования разрешений есть в STORE-LISTING.txt) → отправьте на проверку.
  Проверка обычно занимает от нескольких дней. Убедитесь, что ваша страна есть в списке
  поддерживаемых при регистрации.

Microsoft Edge Add-ons — бесплатно:
  https://partner.microsoft.com/dashboard/microsoftedge → регистрация в программе Microsoft Edge →
  «Create new extension» → тот же roomy-tabs-chrome-0.1.0.zip.

Firefox (addons.mozilla.org) — бесплатно:
  https://addons.mozilla.org/developers/ → «Submit a New Add-on» → «On this site» →
  roomy-tabs-firefox-0.1.0.zip. Проверено официальным валидатором Mozilla: 0 ошибок, 0 предупреждений.
  Сборка указывает, что расширение не собирает данные (data_collection_permissions: none) —
  это обязательное требование для новых расширений Firefox.


ОБНОВЛЕНИЯ
  Каждую новую версию нужно загружать в магазин с увеличенным номером версии (0.1.1, 0.2.0 …).
