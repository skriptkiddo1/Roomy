# Конфиденциальность / Privacy

_Обновлено / Updated: 2026-11-24_

## Roomy (программа для Windows)

- Roomy **не собирает, не отправляет и не продаёт** никакие данные. В программе нет аналитики, рекламы и сетевых запросов.
- Сведения о памяти, процессах, дисках и настройках Windows читаются **только на вашем компьютере** и только чтобы показать их вам.
- Настройки и журнал действий хранятся локально в `%APPDATA%\Roomy`.
- Браузер открывается **только по вашему нажатию**: поиск в интернете по имени программы или страница VirusTotal. Для VirusTotal Roomy вычисляет отпечаток файла (SHA-256) и открывает страницу отчёта по нему — **сам файл никуда не загружается**.

## Roomy Tabs (расширение для браузера)

- Не собирает и не передаёт данные, не делает сетевых запросов, без рекламы и аналитики.
- Сведения о вкладках (адрес, активна ли, закреплена ли, играет ли звук, когда открывалась) используются только чтобы решить, какую вкладку можно усыпить, и не покидают браузер.
- На страницах расширение замечает только **сам факт** начала ввода в текстовое поле, чтобы не усыпить такую вкладку. Что именно вы печатаете, **не читается, не сохраняется и не отправляется**.
- В Chrome и Edge читается объём свободной памяти, чтобы усыплять вкладки раньше, когда её мало.
- Настройки и счётчики хранятся локально в браузере.

---

**English.** Roomy and Roomy Tabs collect, transmit and sell no data, contain no analytics or ads and make no network requests. System, process and tab information is read locally only to show it to you or to decide which tabs can sleep. The extension only notices *that* you started typing (never *what*). A browser page is opened only when you click (web search or a VirusTotal report looked up by the file's SHA-256 hash — the file itself is never uploaded). Settings and logs are stored locally.
